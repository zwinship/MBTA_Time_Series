# MBTA Time Series Project Repository

This repository contains all the data and code used for my MBTA Time Series Project. The project focuses on analyzing and modeling time series data related to MBTA ridership, incorporating various covariates such as weather data, seasonal dummies, and other relevant factors.

The repository includes:

- Raw and processed datasets
- R code for data analysis, model building, and supply function optimization
- A setup that ensures the project is fully reproducible once downloaded. Additionally, the R code is configured to pull data directly from this repository, so manual data downloads are not necessary.
